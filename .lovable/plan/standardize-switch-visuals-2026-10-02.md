# Standardize switch visuals

## Scope
- Use the existing shared Switch control for every boolean switch in the application.
- Replace the two custom switch renderings: the admin premium setting and premium email consent.
- Preserve each switch’s current state, click behavior, labels, disabled/loading behavior, layout, and surrounding design.

## Visual behavior
- OFF: thumb left with a muted track.
- ON: thumb right with the existing primary active track.
- Keep the same behavior and appearance across desktop and mobile.
